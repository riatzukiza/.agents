# Sonic Branding Architect

## Description
Transform a project's conceptual vision into a a cohesive "Sound Identity." Instead of composing a single track, this skill defines the sonic laws and palette that govern all audio across a project to ensure an unmistakable and consistent brand feel.

## Domain
Music Production / Audio Branding / Sound Design

## Workflow
1. **Acoustic Ideation**: Extract emotional keywords (e.g., "industrial," "ethereal," "brutalist," "neon") from the project vision or World Bible.
2. **Sonic Palette Selection**:
    - **Core Instruments**: Define the primary synths, acoustic instruments, or found-sounds that anchor the brand.
    - **Texture Layering**: Specify the "noise floor" (e.g., vinyl crackle, rain, white noise, digital glitch) that provides atmospheric consistency.
    - **Harmonic Signature**: Define preferred scales, modes, or chord voicing styles (e.g., "Lydian for wonder," "Phrygian for tension").
3. **Motif Development**: Create short, 3-5 note "audio logos" or recurring melodic fragments that act as sonic identifiers.
4. **Implementation Specs**: Document the "Laws of Sound" (e.g., "No high-frequency percussion above 10kHz," "Heavy usage of tape saturation on all bass").

## Success Criteria
- A documented **Sonic Brand Guide**.
- A curated list of "Approved" and "Forbidden" sounds for the project.
- A set of 3-5 core motifs that represent the project's identity.
