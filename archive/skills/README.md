# Archived skill candidates

These folders retain their original skill text, contracts and provenance but are
outside the canonical `skills/` discovery root. They are historical material,
not active instructions. Content may be narrow, outdated or unsafe to apply
without checking the current task and runtime; it has not been validated merely
by being preserved here.

The November 2026 audit moved one-incident, mechanically generated templates
whose generic steps added little beyond their descriptions. Their detailed
history remains in Git and in each folder's metadata. To reactivate a candidate,
review its evidence, test positive and negative triggers and actual outcomes,
resolve any overlap or stale claims, then move or rewrite it deliberately under
`skills/` with a matching contract and updated references.

Some harnesses support custom skill roots. Do not configure this archive as a
skill source if these entries should remain inactive.
